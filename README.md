# Arbitrary Precision Calculator (APC)
A calculator that performs arithmetic on very large numbers using a Doubly Linked List in C.

## Operations
- Addition +
- Subtraction -
- Multiplication *
- Division /

## Compile
make

## Run
./apc <number1> <operator> <number2>

## Example
./apc 99999999999999999999 + 88888888888888888888
Result : 188888888888888888887
